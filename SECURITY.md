# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, either:

- through GitHub's **Report a vulnerability** button (Security tab of this repository), or
- by e-mail to security@perimetry.cloud.

Please include the version, the steps to reproduce and the impact you see. We answer within two business days, keep you informed until the fix is released, and credit you if you wish. Please test only against your own sites.

The full policy, including the service side, is at https://perimetry.cloud/security/#report and in https://perimetry.cloud/.well-known/security.txt.

## Supported versions

Only the latest release receives security fixes.
